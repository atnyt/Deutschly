How to use the result

  • IPA shows phonetic transcription only when the dictionary provides it.
  • Recorded audio is source audio; the player appears only when an audio file is available.
  • Device voice is synthetic speech, not a native-speaker recording.
  • Compare the sound with IPA; spelling alone does not guarantee pronunciation.

Accuracy & transparency

This is a learning aid, not a certified pronunciation test. The current lookup uses structured Wiktionary-derived data via Wiktapi. The linked Wiktionary page is a reference for checking the entry; it is not presented as a second independently queried data feed. Regional variants and missing recordings may occur.

Built for careful German practice.
